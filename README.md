# 🌦️ Weather App
Search for any city and get its current weather, built with vanilla HTML, CSS, and JavaScript using the OpenWeatherMap API.

🔗 [Live Demo](https://weather-feeoendba-adam-kirikisla.vercel.app/)

## Features
* Live weather search by city name
* Displays temperature (°C), humidity, and conditions
* Clean error handling for invalid or empty searches
* API key kept secure via a Vercel serverless function (never exposed in the browser)

## Built With
* HTML
* CSS (custom card UI, gradients)
* JavaScript (DOM manipulation, Axios, no frameworks)
* OpenWeatherMap API
* Vercel Serverless Functions
